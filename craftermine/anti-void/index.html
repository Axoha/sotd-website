More About the Game

Craftermine ANTI-VOID is a very intense program. Make sure your device meets the minimum requirements before attempting connection.

Craftermine Forge 1.20.1 is required to run this program. There is a tutorial written in the help page.

This project was only possible thanks to the many dedicated fans and developers. Their names and several modifications are listed.

For your safety, please consult with a doctor before playing.

There may be real players in your offline world, that is a bug we are currently working hard on fixing.
